# CODEVEDX
Amazon Sales Analysis using SQL

This project focuses on analyzing Amazon sales data using SQL to extract valuable business insights. The dataset was imported into MySQL and structured into relational tables for customers, products, and orders.

Features
Database creation and normalization
Data import and preprocessing
Revenue analysis
Top-selling products identification
Category and brand performance analysis
Customer spending analysis
Order status tracking
City-wise sales analysis
Discount and shipping cost impact analysis
Technologies Used
SQL
MySQL
Key Insights
Total revenue generated
Best-performing products and categories
Highest revenue-generating brands
Top customers by spending
Regional sales trends
Effect of discounts and shipping costs on revenue
Project Goal

The main objective of this project is to use SQL queries to transform raw sales data into meaningful business insights for decision-making.
